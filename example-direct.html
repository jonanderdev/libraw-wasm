LibRaw Direct-Mode Test

This page loads libraw via ./dist/direct.js — no inner Web Worker, WASM hosted in this page directly. Decoded pixels are rendered to the canvas below as a sanity check.

The rendered preview applies a quick gamma curve only (raw libraw output is dark/linear-ish). It won't look like a finished JPEG — scannd's pipeline applies its own tone curve. The point is to confirm the bytes are valid image data, not garbage.
